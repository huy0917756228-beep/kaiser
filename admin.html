Lưu Dữ Liệu Vào Thư Mục Google Drive (anticodon)

✅ Tệp users_database.json đã được tạo và tải về máy tính của bạn!

Để tệp xuất hiện ngay lập tức trong thư mục anticodon trên Google Drive của bạn, bạn có thể thực hiện theo 2 cách:

⚡ Cách 1: Kéo thả tệp vào Google Drive (Chỉ mất 2 giây)

Trên cửa sổ Google Drive thư mục anticodon bạn đang mở:

  1. Vào thư mục Downloads (Tải về) trên máy tính của bạn để thấy tệp users_database.json.
  2. Kéo tệp `users_database.json` và thả trực tiếp vào cửa sổ Google Drive (nơi có dòng chữ "Hãy thả tệp ở đây").
  3. Tệp sẽ xuất hiện ngay trong thư mục anticodon trên Google Drive!
📂 Mở Google Drive Của Bạn ↗

🤖 Cách 2: Tự động hóa 100% qua Google Apps Script (Không cần kéo thả)

Tạo một Webhook miễn phí trên chính tài khoản Google của bạn để mỗi lần bấm "Đồng Bộ Lên Drive", tệp sẽ tự động bay thẳng vào thư mục anticodon:

  1. Truy cập script.google.com ➔ Nhấn Dự án mới (New project).
  2. Xóa hết mã cũ, dán đoạn mã bên dưới vào ➔ Nhấn Triển khai (Deploy) ➔ Tùy chọn triển khai mới (New deployment).
  3. Chọn loại là Ứng dụng web (Web app), mục "Người có quyền truy cập" chọn Bất kỳ ai (Anyone) ➔ Bấm Triển khai.
  4. Sao chép URL Web App (dạng https://script.google.com/macros/s/.../exec) dán vào ô bên dưới:
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var folders = DriveApp.getFoldersByName("anticodon");
  var folder = folders.hasNext() ? folders.next() : DriveApp.createFolder("anticodon");
  var files = folder.getFilesByName("users_database.json");
  var file = files.hasNext() ? files.next().setContent(JSON.stringify(data, null, 2)) : folder.createFile("users_database.json", JSON.stringify(data, null, 2), MimeType.PLAIN_TEXT);
  return ContentService.createTextOutput(JSON.stringify({status: "success", fileId: file.getId()})).setMimeType(ContentService.MimeType.JSON);
}
